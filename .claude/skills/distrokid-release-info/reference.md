# Apple credit roles

Read this file before suggesting `creditPerformerRole` or `creditProducer`. Copy one string exactly. DistroKid rejects anything that is not in the dropdown.

`creditPerformerRole` is who played or sang. `creditProducer` is the production role. The defaults are `Unknown` for the performer role and `Producer` for the producer role. The name fields are the person's name, confirmed by the user.
